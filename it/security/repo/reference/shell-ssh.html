Stručný přehled k lekci 1 · Bandit.

SSH

Příkaz nebo souborVýznam
ssh -p 2222 eva@serverPřipojení na jiný než výchozí port 22
exitKonec relace
~/.ssh/known_hostsKlíče serverů, ke kterým ses už připojil
Změněný klíč serveruTřeba reinstalace, ale i útok. Zjisti důvod jinou cestou a až potom se připoj.

SSH klíče a otisky

PříkazVýznam
ssh-keygen -t ed25519Nový pár klíčů
ssh-copy-id eva@serverPřenese veřejný klíč na server
ssh-keygen -lf soubor.pubOtisk klíče
ssh-keygen -R serverSmaže server ze známých hostitelů. S portem: -R '[server]:2222'
ssh -o PubkeyAuthentication=no eva@serverZkouška, že server heslo odmítne
sudo sshd -t / sudo sshd -TKontrola konfigurace / výsledné hodnoty z disku

Ve skriptech

rm -- "$f"

Uvozovky brání dělení na slova, -- výkladu názvu jako přepínače. Název souboru ber jako vstup, který může ovládat někdo jiný.

Kde cvičit: vlastní stroje a cíle, kde to provozovatel výslovně dovoluje. Přístup není povolení (§ 230 trestního zákoníku).
